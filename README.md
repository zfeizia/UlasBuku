# UlasBuku

Aplikasi mobile Android untuk menulis ulasan buku.
Pengguna dapat mencari buku, memberikan rating, menyimpan daftar bacaan, dan berinteraksi dengan ulasan pengguna lain.

---

## Fitur Utama

| Fitur | Keterangan |
|-------|------------|
| Autentikasi | Login dan registrasi akun pengguna |
| Pencarian | Cari buku berdasarkan judul atau penulis |
| Ulasan & Rating | Tulis ulasan dan berikan rating bintang |
| Suka Ulasan | Menyukai ulasan dari pengguna lain |
| Daftar Simpan | Simpan buku ke daftar bacaan pribadi |
| Profil | Lihat profil dan riwayat ulasan sendiri |
| Kategori | Filter buku berdasarkan genre |

---

## Teknologi

- **Bahasa** : Kotlin
- **UI** : Jetpack Compose
- **Arsitektur** : MVVM (Model-View-ViewModel)
- **Tools** : Android Studio

---

## Cara Menjalankan

1. Clone repository ini
   ```bash
   git clone https://github.com/zfeizia/UlasBuku.git
   ```
2. Buka project di **Android Studio**
3. Tunggu proses **Gradle sync** selesai
4. Jalankan di emulator atau perangkat Android (minimal **API 26 / Android 8.0**)
